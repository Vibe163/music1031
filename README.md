# 本地音乐 (LocalMusic)

一款纯离线的 Android 本地音乐播放器，酷狗蓝风格界面，支持手动添加手机本地音乐文件或整个文件夹、歌单管理、沉浸式播放页；内置「创作者训练空间」——一个抖音风格的本地图文/视频作品发布与浏览模块。

## 功能

### 音乐导入
- **手动导入**：通过系统文件选择器添加单个/多个音乐文件，或选择整个文件夹批量导入
- **外部打开**：其他 App 中「用本地音乐打开」音频文件（`ACTION_VIEW`），自动导入曲库并直接播放；App 运行中再次打开也支持
- **导入去重**：按 MD5 内容哈希去重（回退「标题+时长±1.5s」并回填 md5）
- **持久授权**：选中的文件/文件夹通过 SAF 持久化读取权限，重启后仍可播放
- **导入日志**：每次导入记录新增/重复/失败明细，可在设置页查看

支持格式：mp3 / flac / wav / m4a / aac / ogg / opus / wma / mid / amr / mka / aiff 等。

### 曲库与歌单
- **主收藏歌单**：所有导入的音乐自动进入「主收藏」，作为曲库的总入口
- **最近播放**：开始播放即自动记录的虚拟歌单
- **自建歌单**：新建 / 重命名 / 删除歌单，把曲库中的歌曲添加到任意歌单
- **搜索**：按歌曲名 / 艺术家 / 专辑搜索
- **排序**：按添加时间 / 标题 / 艺术家 / 专辑排序
- **定位正在播放**：曲库列表一键滚动到当前播放项

### 播放器
- **播放控制**：播放/暂停、进度拖动、上一首/下一首（播放超过 3 秒才切上一曲，否则回开头）、随机播放、列表循环、单曲循环
- **倍速播放**：0.5x / 0.75x / 1.0x / 1.25x / 1.5x / 2.0x（底层支持 0.25x–3.0x）
- **播放队列管理**：查看队列、点选跳播、移除单曲、清空队列、歌曲菜单「下一首播放」
- **单曲容错**：单首歌曲播放失败时自动跳过，不中断整个队列
- **睡眠定时**：5 / 10 / 15 / 30 / 60 分钟后自动暂停，播放页显示剩余时间
- **音量控制**：播放页内滑杆直接调节系统媒体音量
- **沉浸式播放页**：黑胶唱片风格封面（滑动手势切歌）+ Palette 从封面取色生成模糊动态背景 + 播放队列面板
- **底部迷你播放器**（上一首/播放/下一首 + 播放时缓慢旋转的封面）+ 系统通知栏控制 + 后台播放

### 数据工具
- **歌曲信息编辑**：用 JAudioTagger 把标题/艺术家/专辑等写回文件本体的 ID3/Vorbis/MP4 标签，并按新标题同步重命名文件、回写数据库
- **分享音频**：把音频文件经 FileProvider 复制到缓存后走系统分享面板
- **重复歌曲扫描**：MD5 + Chromaprint 音频指纹双通道检测（指纹结果有缓存表，二次扫描更快），可试听确认、仅删曲库或连文件一起删
- **歌单迁移**：歌单导出为 JSON 文件 / 从 JSON 导入，跨设备迁移时按 5 级策略（MD5 > 标题+艺术家+时长 > 文件名+时长 > 去扩展名文件名 > 仅时长）自动匹配本地歌曲
- **失效 URI 自修复**：启动时一次性探测历史遗留的失效文件引用，按文件名自动修复

### 创作者训练空间
一个完全本地、抖音风格的图文/视频作品模块（底部导航第 3 个 tab 进入；进入后自动暂停外部音乐播放并沉浸全屏）：

- **作品流**：横/竖页 Pager 浏览图片与视频作品，视频首帧 + 播放器组件
- **发布作品**：从系统相册选视频/图片（支持多选、1:1 发布页相册）、选本地 BGM、填写标题/话题/@/位置等
- **个人主页**：1:1 复刻抖音用户主页——头像/昵称/简介编辑、头像裁剪、作品九宫格、点赞/关注、搜索
- **互动**：点赞、评论底部弹窗、分享面板
- **数据持久化**：作品与用户资料以 JSON 存于应用内部存储（`WorkStore` / `UserProfileStore`，应用级单例共享）

### 其他
- **深色模式**：跟随系统 / 浅色 / 深色
- **后台播放细节**：媒体前台服务 + `PARTIAL_WAKE_LOCK`（锁屏可继续解码）、拔耳机自动暂停、音频焦点自动管理（来电/其他 App 播放时暂停）
- **图片性能**：导入时封面降采样为 300×300 缩略图存内部存储，Coil 全局配置内存/磁盘缓存，列表滚动不反复解码
- **完全离线**，无任何网络权限

## 添加音乐的方式

应用采用 **手动添加** 模式（不自动扫描全设备）：

1. 在「本地音乐」页右上角点 **+**
2. 选择 **选择文件**（系统文件选择器，可多选音频文件）或 **选择文件夹**（选择一个目录，递归导入其中的音频）
3. 导入过程会显示进度；完成后歌曲进入「主收藏」并显示封面
4. 已导入过的歌曲会自动去重

也可以在文件管理器等其他 App 中选择「用本地音乐打开」音频，自动导入并播放。

## 应用结构

底部导航 4 个 tab：**本地音乐**（曲库） · **歌单** · **创作者**（创作者训练空间） · **我的**（设置）

| 页面 | 说明 |
|------|------|
| 本地音乐 | 曲库主界面：虚拟歌单切换、搜索、排序、导入、歌曲菜单 |
| 歌单 | 歌单列表 + 新建；进入详情可播放全部/随机、重命名/删除、批量添加歌曲 |
| 创作者 | 创作者训练空间作品流（独立全屏路由） |
| 我的 | 外观、创作者资料、数据迁移（导出/导入歌单、导入日志、检查重复）、关于 |

## 环境要求

- Android Studio Ladybug (2024.2) 或更新版本
- JDK 17
- Android SDK 35
- 最低支持 Android 8.0 (API 26)

## 在 Android Studio 中打开

1. 启动 Android Studio → **Open** → 选择本仓库根目录（如 `D:\music_repo`）
2. 等待 Gradle Sync 完成（已配置腾讯云 Gradle 镜像 + 阿里云 Maven 镜像）
3. 连接手机（开启 USB 调试）或启动模拟器
4. 点击 **Run** 安装到设备

> 首次启动会请求 **通知权限**（用于媒体通知栏控制，Android 13+）。添加音乐不需要存储权限（SAF 由用户主动授权）；创作者空间发布作品需要相册读取权限（Android 13+ 为 `READ_MEDIA_IMAGES` / `READ_MEDIA_VIDEO`）。

## 技术栈

| 模块 | 技术 |
|------|------|
| UI | Jetpack Compose + Material 3（酷狗蓝主题） |
| 架构 | MVVM + ViewModel |
| 播放 | Media3 ExoPlayer 1.5 + MediaSession（媒体前台服务、音频焦点、WakeLock） |
| 存储 | Room 数据库（歌曲持久化 + 歌单关联 + 导入日志 + 指纹缓存） |
| 文件选择 | SAF（OpenDocument / OpenDocumentTree / CreateDocument） |
| 元数据 | MediaMetadataRetriever（读：标题/艺术家/专辑/时长 + 嵌入式封面）；JAudioTagger（写：ID3/Vorbis/MP4 标签落盘） |
| 封面加载 | Coil（视频首帧解码支持） |
| 取色 | Palette（播放页动态背景） |
| 音频指纹 | Chromaprint 移植（FFT + chroma + 汉明距离判重） |
| 作品数据 | kotlinx-serialization JSON |

## 架构要点

- **歌曲持久化**：导入的歌曲存入 Room `songs` 表（`SongEntity`），重启不丢失；歌单通过 `playlist_songs` 关联表引用稳定的 `songs.id`。
- **主收藏 = 曲库**：「主收藏」是虚拟歌单（固定 id = `FAVORITES_PLAYLIST_ID`），其内容即整个 `songs` 表，无需冗余关联；「最近播放」同理（`RECENTLY_PLAYED_PLAYLIST_ID`）。
- **封面**：导入时通过 `MediaMetadataRetriever.embeddedPicture` 提取嵌入式封面，保存到内部存储 `filesDir/albumart/<songId>.jpg`，UI 用 Coil 加载，避免列表滚动时反复解码。
- **双层播放架构**：`MusicPlayerService`（`MediaSessionService`，系统侧，管理音频焦点/WakeLock/通知栏）+ `PlayerController`（应用侧 `MediaController` 封装，暴露 StateFlow 给 ViewModel）。
- **重复扫描**：先 MD5 全量比对，未命中再算 Chromaprint 指纹做「近似重复」判定（滑动对齐 + 平均汉明距离），指纹按 `songId` 缓存在 Room，文件未变更则复用。
- **歌单迁移**：JSON 仅存歌曲引用（标题/艺术家/时长/md5），不复制文件；导入端按 5 级策略匹配本地已有歌曲。
- **创作者空间数据**：`WorkStore` / `UserProfileStore` 为应用级单例（`LocalMusicApp` 持有），发布/浏览/主页各 ViewModel 共享同一份数据源。

## 权限

| 权限 | 用途 |
|------|------|
| `FOREGROUND_SERVICE` / `FOREGROUND_SERVICE_MEDIA_PLAYBACK` | 媒体播放前台服务 |
| `POST_NOTIFICATIONS` | 媒体通知栏（Android 13+ 运行时请求） |
| `WAKE_LOCK` | 锁屏后台解码 |
| `READ_MEDIA_IMAGES` / `READ_MEDIA_VIDEO`（Android 13+）、`READ_EXTERNAL_STORAGE`（≤12） | 创作者空间读取系统相册发布作品 |

> 曲库导入全程走 SAF，**不申请** `READ_MEDIA_AUDIO` / 存储权限。

## 辅助工具

### `music_duplicate_checker.py`（PC 端）

独立的 Python 命令行工具，递归扫描文件夹中的音乐文件，按 MD5 找出完全重复文件并输出报告。先按文件大小预筛再对同大小文件流式算 MD5，速度快。

```bash
python music_duplicate_checker.py <音乐文件夹> [--threads N] [--no-size-filter] [--min-size 字节] [--ext .mp3,.flac] [--out 报告.txt]
```

## 构建说明

- `gradlew` 无参数默认执行 `assembleRelease`（debug 构建的 Compose 有 2–5 倍性能损耗，日常开发/测试建议装 release 版）
- release 使用 debug 签名（仅为方便本地安装，非发布配置）
- Gradle 8.9 走腾讯云镜像，Maven 依赖优先走阿里云镜像；JAudioTagger Android fork 走 jitpack
- 插件版本：AGP 8.7.3 / Kotlin 2.0.21 / KSP 2.0.21-1.0.28

## 注意事项

- 应用完全离线，不包含任何网络权限
- 若导入后无封面，说明该音频文件未内嵌封面图，会显示默认音符占位图
- 若扫描不到音乐，请确认选择了正确的音频文件/文件夹
- 创作者空间的作品数据保存在应用内部存储，卸载应用会一并清除
